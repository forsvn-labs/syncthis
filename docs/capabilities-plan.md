# Superseded capabilities plan

The former capability-centric roadmap is superseded by the [plugin product contract](plugin-product-contract.md).

Syncthis has one product object: an Agent Plugin. Skills and MCP configuration remain private adaptation mechanisms used only when a target cannot consume the plugin natively. Current host behavior and the canonical `native`, `adapted`, `partial`, `blocked`, and `unsupported` outcomes are documented in the product contract and README.
