# Project context

Read the four authoritative root records before project work. Start with
the PROGRESS snapshot and STRUCTURE's "Read before changing" section.
Use the `horsemen` skill to update the records.

- [VISION.md](VISION.md): product, users, outcomes, scope, and non-goals.
- [BRAIN.md](BRAIN.md): knowledge homes, stable key, save rules, and access.
- [PROGRESS.md](PROGRESS.md): dated evidence, work state, blockers, and next steps.
- [STRUCTURE.md](STRUCTURE.md): code and external knowledge architecture.

[README.md](README.md) is the short setup entry. [CHANGELOG.md](CHANGELOG.md)
records factual delivery history. Keep lifecycle updates in PROGRESS.
